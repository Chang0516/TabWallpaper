# Tab 壁纸（Android 平板动态壁纸）

- **打横**：永远显示完整照片，两边空位用同一张照片的模糊版填满
- **打直**（二选一，App 里切换）：
  - **自己框选**：每张照片可以单独框出打直时要显示的画面
  - **跟着滑动**：桌面最左页显示照片最左边，往右滑，画面跟着移到中间、右边
- **双击桌面空白处**：换下一张你选的照片（淡入淡出）

## 怎么装到平板上

1. 电脑安装 **Android Studio**（免费）：https://developer.android.com/studio
2. 解压这个文件夹，Android Studio → **Open** → 选 `TabWallpaper` 文件夹，等它自动下载需要的东西（第一次要几分钟）
3. 平板：设置 → 关于平板 → 软件信息 → 连按「版本号」7 次，打开开发者选项；再到 开发者选项 打开 **USB 调试**
4. 用 USB 线连上电脑，Android Studio 上方选你的平板，按绿色 ▶ **Run**

不想连线的话：Build → Build App Bundle(s) / APK(s) → Build APK(s)，把生成的 `app-debug.apk` 传到平板上安装。

## 怎么用

1. 打开「Tab 壁纸」→ **添加照片**（可以一次选好几张）
2. 选择竖屏模式；选「自己框选」的话，每张照片点 **框选**，拖动和双指缩放到满意后按 **保存**
3. 点 **设为桌面壁纸** → 确认（可以选只设桌面，或者桌面 + 锁屏）

## 注意

- **三星 One UI 的桌面**通常不会告诉壁纸“现在滑到第几页”。遇到这种情况，App 会改成直接跟着手指在桌面上左右滑的距离来移动画面。想要最准确的分页效果，可以换 Nova Launcher、Lawnchair 这类桌面。
- 双击没反应的话，看看三星 设置 → 高级功能 → 动作与手势 里有没有开「双击关闭屏幕」，这个可能会抢走双击。
- 照片要一直留在平板上。删掉或移动了原图，壁纸就读不到了。
- 只支持 Android（9.0 以上）。iPad 不允许 App 设置桌面壁纸。
